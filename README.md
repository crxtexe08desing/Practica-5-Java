# Practica 5 - POO y Fundamentos de Java con Retos (SIS-211)

Un directorio independiente por ejercicio, cada uno con su codigo, `Main.java` y `README.md`.

| Carpeta | Tema |
|---|---|
| `ejercicio1_cuenta_digital` | Encapsulamiento y validaciones |
| `ejercicio2_pedido_cafeteria` | Composicion y arreglos |
| `ejercicio3_tarifas_entrega` | Herencia, sobrescritura, sobrecarga |
| `ejercicio4_sensores_invernadero` | Clase abstracta e interfaz |
| `ejercicio5_prestamo_libro` | Asociacion entre objetos |
| `ejercicio6_empleados_tienda` | Herencia y polimorfismo |
| `ejercicio7_revision_ia` | Revision de codigo con IA |
| `ejercicio8_validador_claves` | Validador didactico con IA |
| `ejercicio9_auditoria_login` | Auditoria local y bytecode |

## Compilar y ejecutar (cualquier ejercicio)
```
cd ejercicioN_...
javac *.java
java Main
```
Version de Java usada: OpenJDK 21. Todos los datos son ficticios; no hay contrasenas, tokens ni datos personales reales.

## Pendiente de completar por ti
Los ejercicios 7, 8 y 9 exigen el **prompt que tu uses con tu IA**, sus sugerencias y tu clasificacion. Estan marcados como `COMPLETAR` en sus README: no se pueden inventar porque la evidencia debe ser tuya. Haz esa consulta, ejecuta las pruebas y rellena esas secciones antes de subir a GitHub.
